TASCI

A ridiculously lightweight terminal code editor written in C.

 • ~50KB binary
 • Syntax highlighting
 • Theme creator
 • Keyboard-focused workflow
 • Fast startup
 • Linux native 

But why use TASCI?
Most text editors are light but this one is even lighter, if you want a light text editor that looks good by default you should at least try it out.
